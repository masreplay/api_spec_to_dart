## 1.0.0

**Breaking rewrite.** The package now lives in the
[api_spec_to_dart](https://github.com/masreplay/api_spec_to_dart) monorepo
and is reinstated on pub.dev.

- **Typed models generated from the official schema.** Every model is
  generated by swagger_to_dart from Postman's v2.1.0 collection JSON Schema
  (`make models`), replacing the hand-written 0.x models. Every "one of" in
  the schema is a sealed class (`PostmanItems`, `PostmanRequest`,
  `PostmanUrl`, `PostmanDescription`, …); unknown enum values decode to
  `unknown`. See the README for the full list.
- **Postman → OpenAPI converter** (`postmanToOpenApi`) for v1, v2.0, v2.1,
  the Postman API envelope and v3 directories
  (`package:postman_collection/io.dart`), with `normalizePostmanCollection`,
  `isPostmanCollection`, `postmanCollectionFromV3Files` and
  `inferJsonSchema`.
- **No dio or retrofit dependency.** The request-capture helpers moved to a
  dio interceptor recipe in the example.

### Migrating from 0.x

| 0.x | 1.0.0 |
|---|---|
| `PostmanCollection` | `PostmanCollection` (`item` is `List<PostmanItems>`) |
| `PostmanCollectionItem` (request or folder) | sealed `PostmanItems`: `PostmanItemsItem(PostmanItem)` or `PostmanItemsItemGroup(PostmanItemGroup)` |
| `PostmanCollectionRequest` | sealed `PostmanRequest`: `PostmanRequestObject(PostmanRequestObjectValue)` or `PostmanRequestString` |
| `PostmanCollectionRequestMode`, `PostmanFormDataEntry` | `PostmanRequestObjectValueBody` (`mode`: `PostmanRequestObjectValueBodyMode`), `PostmanUrlEncodedParameter`, sealed `PostmanFormParameter` |
| `PostmanCollectionUrl` | sealed `PostmanUrl` (`PostmanUrlObjectValue` or a string) |
| `PostmanCollectionResponse` | `PostmanResponse` |
| `PostmanCollectionInfo`, `…Auth`, `…AuthAttribute`, `…AuthType`, `…Header`, `…QueryParam`, `…Variable`, `…VariableType`, `…Event`, `…Script`, `…Cookie`, `…Certificate`, `…ProxyConfig`, `…Version` | `PostmanInfo`, `PostmanAuth`, `PostmanAuthAttribute`, `PostmanAuthType`, `PostmanHeader`, `PostmanQueryParam`, `PostmanVariable`, `PostmanVariableType`, `PostmanEvent`, `PostmanScript`, `PostmanCookie`, `PostmanCertificate`, `PostmanProxyConfig`, `PostmanVersion` |
| `PostmanCollectionDocumentationMixin`, `getRequestOptionsFromRetrofit`, `PostmanCollectionRequest.fromRequestOptions` | Removed: copy the `PostmanRecorder` interceptor from `example/lib/src/dio_recipe.dart` |
| `toSentenceCase` | Removed |

Fields the 0.x models added outside the schema (such as a response's
`postmanPreviewLanguage`) are gone; the models hold exactly what the official
schema defines.
